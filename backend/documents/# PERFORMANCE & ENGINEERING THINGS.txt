## 🔑 The Big Decision First

**Use GROQ for everything possible.**

Here is why — Groq runs on custom LPU chips, not GPUs. This gives you:

- Sub-100ms time-to-first-token for most models
- 3-10x faster inference than GPU-based providers
- A free tier that actually works
- **One API key, one platform — STT + LLM + TTS all from Groq**

This is perfect for your assignment because everything stays under 450ms.

---

## 🎙️ STT — Speech To Text

**Use: Groq + Whisper Large v3 Turbo**

| Detail | Value |
|---|---|
| Model | `whisper-large-v3-turbo` |
| Speed | 228x real-time speed |
| Free tier | 2,000 requests per day, 7,200 audio seconds per hour |
| Expected STT latency | ~80-120ms |
| File format tip | Use WAV format for lower latency |
| Free tier file size | Up to 25MB for free tier |

**Why not Deepgram?** Deepgram is excellent but requires paid plan for streaming. Groq Whisper is free and faster for this assignment.

**Hindi/Tamil note:** Whisper Large v3 natively supports Hindi and Tamil. You do not need a separate model.

---

## 🤖 LLM — AI Agent Brain

**Primary: Groq + Llama 3.3 70B (for reasoning)**
**Fast fallback: Groq + Llama 3.1 8B (for simple turns)**

| Model | Speed | Best For | Free? |
|---|---|---|---|
| `llama-3.3-70b-versatile` | ~200ms TTFT | Complex booking logic, conflict handling | ✅ Yes |
| `llama-3.1-8b-instant` | ~80ms TTFT | Simple confirmation turns | ✅ Yes |

**Why Llama 3.3 70B on Groq?**

- Groq Llama 3.3 70B at 394 TPS responds 5x faster than GPT-4o Mini
- Native function calling support, JSON mode for structured output, 128K token context window
- Free tier available

**Smart strategy for your project:**

Use **Llama 3.1 8B** for simple yes/no turns like "Confirm appointment?" and **Llama 3.3 70B** only for complex reasoning like conflict detection. This keeps average LLM latency under 150ms.

---

## 🔊 TTS — Text To Speech

**Use: Groq + Orpheus TTS (for English)**
**Use: Google Cloud TTS free tier (for Hindi + Tamil)**

### For English:

Orpheus TTS by Canopy Labs is now live on GroqCloud, delivering up to ~100 characters/second with ultra-low latency, supporting six professionally-trained English voices with bracketed vocal directions like [cheerful] or [whisper].

Model ID: `orpheus-tts-v1` on GroqCloud

### For Hindi and Tamil:

Groq TTS currently supports English and Arabic only. For Hindi and Tamil you use **Google Cloud TTS free tier**:

- Google Cloud TTS gives 1 million characters free per month
- Supports Hindi (`hi-IN`) and Tamil (`ta-IN`) natively
- Latency: ~100-150ms

**Combined TTS latency target:** under 130ms average.
