# Application Modules

## 1. Authentication Module

Handles user registration, login, authentication, and authorization.

Main operations:

- User registration
- User login
- JWT token generation
- Current user information
- Role-based access control

---

## 2. User Module

Manages user-related information and operations.

Main operations:

- User management
- User profile information
- User roles
- User authentication data

---

## 3. Event Module

Handles creation and management of events.

Main operations:

- Create events
- View events
- View published events
- Update events
- Delete events
- Manage event status
- Manage event capacity
- Manage registration deadlines

---

## 4. Registration Module

Handles event registrations.

Main operations:

- Create registration
- View registrations
- View registration by ID
- View user registrations
- View event registrations
- Cancel registration

---

## 5. Venue Module

Manages event venue information.

Main operations:

- Create venues
- View venues
- Update venue information
- Manage venue capacity
- Manage venue location details

---

## 6. Payment Module

Handles payment-related functionality associated with events and registrations.

---

## 7. Feedback Module

Handles feedback submitted by users regarding events and the system.

---

## 8. Administration Module

Provides administrative functionality.

Main operations:

- Manage events
- Manage users
- Manage registrations
- Manage venues
- Manage payments
- Manage feedback
- Monitor AI agent activity
- Manage AI knowledge documents

---

## 9. AI Assistant Module

Provides conversational AI functionality.

Main operations:

- User chat
- Public chat
- Chat sessions
- AI agent execution
- Natural-language interaction
- Application tool usage

---

## 10. RAG / Knowledge Module

Manages the knowledge base used by the AI assistant.

Main operations:

- Knowledge document upload
- Document ingestion
- Document processing
- Text retrieval
- Vector search
- Knowledge-base status

---

## 11. AI Monitoring Module

Provides administrative monitoring of AI agent activity.

Main operations:

- View agent activity
- View individual agent runs
- Monitor AI execution information
