# User Guide

## 1. Registration

1. Open the Smart Event Management System.
2. Select the registration option.
3. Enter the required user details.
4. Submit the registration form.
5. Log in using the registered credentials.

---

## 2. Login

1. Open the login page.
2. Enter the registered email and password.
3. Submit the login form.
4. After successful authentication, the user can access available features.

---

## 3. Browse Events

Users can:

- View available events
- View published events
- Open event details
- Check event information
- Check registration availability

---

## 4. Event Registration

1. Select an available event.
2. Open the event details.
3. Select the registration option.
4. Submit the required information.
5. The registration is stored in the system.

---

## 5. Manage Registrations

Users can view their registrations.

Users can also cancel a registration when cancellation is supported.

---
