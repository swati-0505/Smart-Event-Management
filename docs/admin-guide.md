# Admin Guide

## 1. Admin Access

Administrative features are protected using role-based access control.

Only users with the required administrator role can access administrative operations.

---

## 2. Event Management

Administrators can:

- Create events
- View events
- Update events
- Delete events
- Manage event status
- Manage event capacity
- Manage registration deadlines

---

## 3. Registration Management

Administrators can access registration information for events and users.

Available operations include:

- View registrations
- View event registrations
- View user registrations
- Manage registration-related information

---

## 4. Venue Management

Administrators can manage venue information used for events.

Venue information includes:

- Venue name
- Address
- City
- Capacity

---

## 5. Payment Management

Administrators can access payment-related functionality provided by the system.

---

## 6. Feedback Management

Administrators can manage feedback submitted through the system.

---

Administrators can manage documents used by the AI/RAG system.
